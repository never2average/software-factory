# CARO: what the clauses generally cover

Use the numbering printed in the report. The Order has been reissued over the years and the clause list has changed;
the table below is an orientation for the version most recent reports use, not a text to quote. If the report's
clauses differ, follow the report and say which clause numbers it uses.

## Classifying what you read

| Class | Test | Example wording |
|---|---|---|
| Qualified / adverse remark | The auditor states non-compliance, default, disagreement or inability to verify | "has defaulted", "are not in agreement", "has not been complied with", "we are unable to comment" |
| Factual disclosure | The clause requires a list and the auditor gives it, without stating non-compliance | disputed dues table; frauds reported; title deeds list; delays of a few days in depositing dues "in a few cases" (borderline: quote and let the analyst judge) |
| Clean | Plain negative or confirmation | "has not defaulted", "no fraud ... noticed", "not applicable" |

When unsure between the first two, quote and label it "remark - classification unclear". Never soften a remark, and
never upgrade a factual disclosure to a qualification.
