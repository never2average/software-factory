## Where data is stored

| | |
|---|---|
| Database | Postgres at the address the server is configured with (DATABASE_URL), else an embedded database on the server's disk |
| In the database | workspaces, people, keys (hashed), runs and their results, usage, settings, and every record area's rows; each workspace's rows under row-level security. Workspace credentials and the key vault's provider keys are stored sealed (AES-256-GCM): credentials with the workspace's own data key, provider keys with the vault's master key (APP_VAULT_KEY), never in clear |
| Object store | this server uses Cloudflare R2 when R2_BUCKET, R2_ENDPOINT and its two keys are set, else a directory named by APP_STORAGE_DIR |

## Where model calls go

| | |
|---|---|
| Gateway | every model call a run makes goes to this service's inference gateway (/gw/<provider>), which checks the run's token, meters tokens and cost against the run's budget, and forwards the call with a key from the key vault |
| Providers | no job kind of this build names a model provider |
| The server's own model calls | the docs answers in the console, and a pack's code when it asks the shell for one (src/ask-model.ts): sent by this server with a key from the key vault to the first model that answers among GLM on Cloudflare Workers AI, Claude (Anthropic's API, or Claude on Google Cloud Vertex AI) and the orchestrator's OpenAI model; metered, and not through a run's gateway token |
