Connect Octillion

Octillion is the APO (Agentic Preference Optimization) platform, and it lives inside Claude and ChatGPT. Add it as a connector, sign in, install the skill, and ask it to onboard your product.

Your connector URL

It is the same for everyone and has no secret in it: you sign in with your work email when your client asks (accept your invitation email first).

https://octillion.useimmaculate.com/mcp

If you were given an API key (oct_…) instead, your client sends it as a header, Authorization: Bearer <key>, never in the URL. Claude and ChatGPT cannot send a header: ask for a sign-in invitation to use them. Per-client setup is on your setup page.

Claude (web & desktop)

  1. Open Settings → Connectors. On Team and Enterprise plans an owner adds it under Organization settings → Connectors.
  2. Click Add custom connector, name it Octillion, paste the connector URL and save, then click Connect and sign in.
  3. In a chat, enable Octillion from the tools menu. Results show up as an interactive dashboard.
  4. Optional but recommended: install the Octillion skill so Claude knows the workflow and reads results carefully.

ChatGPT (web & desktop)

  1. Open Plugins → + and choose Add custom MCP server. On older workspaces this lives under Settings → Apps & Connectors with Developer mode turned on. Business, Enterprise and Edu workspaces may need an admin to allow custom MCP servers.
  2. Name it Octillion, paste the connector URL, choose OAuth, save it as a plugin and sign in.
  3. In a chat, add Octillion from the + menu. ChatGPT renders the same dashboard.

The Octillion skill for Claude

The skill teaches Claude the Octillion workflow and how to report results with confidence intervals and transcript evidence.

Download octillion-skill.zip

  1. In Claude, open Settings → Capabilities → Skills and click Upload skill.
  2. Select octillion-skill.zip. Claude uses it automatically whenever you ask about agent visibility.

Your first run

1. Onboard

“Onboard my product: <one paragraph>. Website https://…, docs https://…”

2. Review

Check the package names, competitors and the generated problems. Ask Claude to fix anything that's off.

3. Read the report

“Show the visibility report and explain our biggest loss with evidence.”

Runs use real coding agents in isolated sandboxes, so they take a few minutes. Agents never see your product's name in a task, which keeps the results honest.
